Perceptron lineal: regresion con una entrada

El modelo recibe una entrada x y produce una salida continua sin funcion de activacion: y_hat = w*x + b. En este caso, aprender significa mover una recta para aproximarse a los puntos de entrenamiento.

Datos de entrenamiento fijos

Cada observacion tiene una entrada x y un objetivo continuo y.

#xobjetivo y
y_hat = 0.00x + 0.00

El perceptron lineal

La conexion multiplica x por el peso w. El sesgo b se suma en la salida.

Recta de regresion

Arrastra para explorar, usa la rueda para acercar y pasa sobre un punto para ver sus valores.
