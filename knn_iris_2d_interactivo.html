K-Nearest Neighbors: clasificar por cercanía

KNN predice la clase de una flor nueva buscando las k flores de entrenamiento más próximas. No aprende pesos ni una fórmula: conserva ejemplos y calcula distancias al predecir.

Cómo decide KNN

Cada punto usa dos variables originales de Iris: pétalo largo y pétalo ancho. La clase más votada entre los vecinos cercanos se convierte en la predicción. Haz clic en el plano para mover la flor nueva.

Aplicaciones reales

Puede recomendar productos desde usuarios similares, identificar casos médicos parecidos o clasificar observaciones cuando la distancia entre casos representa similitud.

Dataset Iris usado por KNN

Cada color identifica una clase. Se reservan 40 flores de cada clase para entrenamiento y 10 para prueba.
