Curva ROC: comparación de niveles de discriminación

Las 12 filas son las mismas observaciones de prueba. Cada columna muestra el score o probabilidad P(1) producido por un modelo con distinta capacidad de separar las clases. Activa o desactiva cada columna para comparar sus curvas ROC.

0.50 Para cada modelo: P(1) ≥ umbral → predicción 1

1. Datos de prueba

Caso Real Pred. Pred. Pred.
Cada fila representa el mismo caso. Lo único que cambia entre columnas es el score asignado por cada modelo.

2. Curvas ROC

Cada curva usa todos los umbrales posibles. El punto sólido sobre cada curva corresponde al umbral actual.

3. Métricas con el umbral seleccionado

Modelo TP FP FN TN TPR FPR AUC

4. Qué observar

  1. Las tres columnas pertenecen a las mismas 12 observaciones.
  2. La diferencia está en qué score asigna cada modelo a cada observación.
  3. Si positivos y negativos se mezclan mucho en los scores, la ROC se acerca a la diagonal.
  4. Si los positivos tienden a recibir scores mayores que los negativos, la ROC se acerca a la esquina superior izquierda.
  5. El AUC resume la capacidad de discriminación de toda la curva.
  6. El umbral no cambia la curva completa: únicamente mueve el punto de operación sobre cada curva.
