Una red neuronal por dentro: aprender XOR

Explora cómo dos valores de entrada atraviesan una capa oculta y producen una probabilidad final. Este ejemplo usa pesos fijos para representar una función XOR: la salida es alta cuando exactamente una entrada está activa.

1. La arquitectura

La red tiene dos entradas, dos neuronas ocultas y una neurona de salida. Cada conexión tiene un peso; cada neurona también incorpora un sesgo.

z = w₁x₁ + w₂x₂ + b   →   a = sigmoide(z)

2. Qué está aprendiendo

XOR devuelve 1 cuando solo una entrada vale 1. No puede resolverse con una sola frontera lineal, por eso ilustra por qué una capa oculta es útil.

XOR(0,0)=0 · XOR(0,1)=1 · XOR(1,0)=1 · XOR(1,1)=0

Idea clave:

La red no recibe la regla XOR escrita en código. Durante el entrenamiento, ajustaría pesos y sesgos para reducir el error. Aquí los pesos ya están fijados para que puedas concentrarte en observar el cálculo de cada neurona.
